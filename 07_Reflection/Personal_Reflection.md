Personal Reflection

Student: MENGWAI, KKE (44419465)
Project: CMPG 325 - Thabang Building Contractors Network Design

What I Learned:
This project taught me how to design and implement a complete enterprise network from scratch. I learned how to apply VLSM to efficiently allocate IP addresses, how to configure VLANs and inter-VLAN routing, how to configure DHCP for automatic IP assignment, how to use extended ACLs to control network access, and how to document a project professionally using GitHub.

Challenges Faced:
-Switch model confusion. I initially used a Layer 2 switch for routing.
-Port limitations. The 3560 only has 2 Gigabit ports.
-Router-on-a-stick versus L3 switch. I switched to router-on-a-stick for reliability.
-ACL application point. I learned that applying it outbound on the WAN interface works best.
-ARP cache issues. I learned to clear ARP when changing gateway configurations.

How I Overcame Them:
I researched the differences between switch models. I tested each configuration step by step. I documented everything in GitHub. I used small command blocks to avoid Packet Tracer errors.

What I Would Do Differently:
I would start with router-on-a-stick from the beginning. I would take more screenshots during the process. I would practice the video demonstration before recording.

Conclusion:
This project has given me practical experience in network design and implementation. I now feel confident in my ability to design, configure, and troubleshoot a small-to-medium enterprise network.
